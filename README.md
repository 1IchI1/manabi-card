# まなびカード

写真と文字で作る、自分専用の暗記カードアプリ（ブラウザだけで動く PWA）。

- スマホで「問題の写真」「答えの写真」を撮ってカード化（切り抜き・回転、アルバムからまとめて追加）
- AI に変換させた単語リスト（Markdown の表 / 箇条書き / Q&A / CSV / Anki 書き出し / JSON）を取り込み
- 判定は「覚えた / 覚えてない」の2択。復習間隔は FSRS-5 で計算し、目標記憶率を設定できる

カードや写真のデータは、使っている端末のブラウザ内（IndexedDB）にだけ保存され、外部には送信されない。
iPhone では Safari で開いて「ホーム画面に追加」して使う。
